#Font Awesome icon management

Instalacion iconos en React:
[Guía oficial](https://docs.fontawesome.com/web/use-with/react#free-icon-packages)
```Node
npm i --save @fortawesome/react-fontawesome@latest
npm i --save @fortawesome/fontawesome-svg-core

#Free Icons
npm i --save @fortawesome/free-solid-svg-icons
npm i --save @fortawesome/free-regular-svg-icons
npm i --save @fortawesome/free-brands-svg-icons




```
Uso iconos en React:
[Referencia](https://docs.fontawesome.com/web/use-with/react/add-icons)

```
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome";
import { faStar, faEnvelope } from "@fortawesome/free-solid-svg-icons";
import { faEnvelope } from '@fortawesome/free-regular-svg-icons'
